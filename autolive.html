HOW AUTO LIVE WORKS

READ-ONLY PHASE
01 / CONNECTChoose one channel

The owner configures the public channel name and API credentials as GitHub settings, never on this page.

02 / MONITORPeriodic live checks

GitHub Actions checks the official platform. Paused or delayed scheduled jobs may miss short streams.

03 / REVIEWInspect real clips

Review published Twitch clips. Only download/edit video you may lawfully reuse.

OWNER SETUP · GITHUB, NO TOKEN IN WEBSITE

In this repository, open Actions Variables and add CUTNOVA_STREAM_PLATFORM = twitch or youtube, plus CUTNOVA_STREAM_CHANNEL = the Twitch username or YouTube @handle/UC channel ID. Only this configured channel is monitored.

In Actions Secrets add TWITCH_CLIENT_ID and TWITCH_CLIENT_SECRET from your own Twitch developer app; or YOUTUBE_API_KEY from a Google Cloud project with YouTube Data API enabled. Do not enter credentials in the public site, issue forms, chat, or code.

Then open Auto Live Monitor, run it once manually, and allow the scheduled checks. GitHub's scheduled checks are approximate, may be delayed/disabled and have quota limits. YouTube searches use API quota.

No source-media recording, AI transcription, clip creation, Instagram DM, or all-night on-device recording occurs in this initial release. A broadcaster-approved clipping pipeline can be added separately.
